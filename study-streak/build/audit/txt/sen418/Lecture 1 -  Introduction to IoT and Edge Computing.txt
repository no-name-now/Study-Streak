Interconnectivity
Devices can communicate with one another or with other systems through networks.
Dynamic Nature
IoT systems are dynamic because their state and environment can continuously change.
Scale
IoT systems can contain a very large number of devices, creating challenges in device management and data processing.
Heterogeneity

Self-Adapting Behavior

The Four Layers of an IoT Ecosystem
1. Sensors & Actuators
Sensors: Detect temperature, motion, light, cameras, GPS.Actuators: Perform physical actions like switching relays, motors, valves, locks.
2. IoT Gateways
Acts as a communication bridge between local sensory devices and remote networks (e.g., Raspberry Pi, industrial smart routers).
3. Cloud / Server
Provides centralized historical storage, heavy databases, artificial intelligence training, and global analytics.
4. Applications
User dashboards, mobile interfaces, automated alert networks, and enterprise enterprise decision support systems.

An actuator is a machine component or system that moves or controls the mechanism of the system. Sensors in the device sense the environment, then control signals are generated for the actuators according to the actions needed to perform.
Actuators
Electric actuators: Use electrical current to drive motors for precise, clean movement.
Hydraulic actuators: Use pressurized liquid to lift or move heavy loads.
Pneumatic actuators: Use compressed air to operate fast-acting industrial valves and switches.

Cloud Computing is the delivery of computing resources such as processing power, storage, databases, networking, software and applications over a network, usually the Internet.
Instead of buying and maintaining a powerful computer yourself, you can rent computing resources from a cloud provider.
Think of the Cloud as a giant collection of computing resources that can provide massive storage, processing and scalable services.
Resources can be scaled vertically or horizontally.

## slide21.xml
Imagine a self-driving car detects an obstacle. If the vehicle must send the information to a distant cloud server, wait for processing, and then receive the response, the delay may be unacceptable.
Car → Internet → Cloud → Processing → Internet → Car → Brake
Latency is the delay between sending information and receiving a response.
For some applications, a delay of several seconds may be acceptable.
For other applications, delays measured in milliseconds can be critical.

Edge Computing
Edge computing is a distributed computing model in which data processing occurs closer to the source of data generation, such as sensors, devices, or local gateways, rather than relying entirely on centralized cloud servers.
Core Insight: The edge handles immediate processing, while the cloud handles things like long-term storage, analytics, dashboards, and large-scale processing.
Traditional Cloud:
CCTV Camera → Local Network → Internet → Cloud Data Center → Processing
The camera's video travels through the network and Internet to a remote cloud server for processing.
Edge Computing:
CCTV Camera → Local Network → Edge Computer → Processing
Here, the camera still communicates over a network, but the edge computer is nearby, often on the same local network.

Benefits of Edge Computing
Low Latency
Processing closer to the device generally reduces the time required to make a decision. This is critical for autonomous vehicles, industrial control, robotics, security systems and real-time monitoring.
Data → Edge → DecisionversusData → Internet → Cloud → Internet → Decision
Bandwidth Savings
The edge can filter, summarize, compress or analyze data before transmission.
Camera produce 100 GB raw data  →  Edge  →  2 GB useful information  →  Cloud

Benefits of Edge Computing Cont’d
Privacy
Some data is sensitive, such as medical information, security camera footage, personal conversations and location data. Local processing can reduce the need to transmit all raw data to a remote cloud environment.
Important: Edge computing does not automatically make a system private or secure. Security and privacy still need to be designed into the system.
