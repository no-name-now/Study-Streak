12. Answers to Questions
1. What is a virtual machine, and what role does Azure play in providing one?
A virtual machine (VM) is a software-based computer that runs its own operating system and applications on shared physical hardware, isolated from other VMs by a hypervisor. Azure acts as the Infrastructure-as-a-Service (IaaS) provider: it owns and maintains the physical servers, hypervisor, storage, networking and data centres, and lets users create, configure, scale and pay for VMs on demand through the Azure Portal, CLI or API.
2. Why must you select a region that is available under your subscription?
Each subscription (especially Azure for Students) is permitted to deploy only to certain regions, and each region offers different VM sizes, images and quota limits. Choosing a region that is not available causes validation or deployment to fail. Region choice also affects latency to users, cost and data-residency requirements; South Africa North was chosen because it was allowed and is close to Nigeria.
3. What is the purpose of the operating system disk, and what factors influence its size and type?
The OS disk is a managed virtual disk that stores the operating system, boot files, installed software and configuration, so the VM needs it to boot and run. Its size is influenced by the image's minimum requirement, the software and data expected to be stored, and cost. Its type (Standard HDD, Standard SSD, Premium SSD, Ultra Disk) is chosen by balancing performance (IOPS and throughput), reliability/SLA and price. Standard SSD at 30 GiB was used as an economical but reliable option for a basic web server.
4. What is the function of an Azure Network Security Group (NSG)?
An NSG is a virtual firewall attached to a subnet or network interface. It contains prioritised inbound and outbound security rules that allow or deny traffic based on source, destination, port and protocol. In this task it allowed SSH (22), HTTP (80) and HTTPS (443) into the VM while blocking other inbound traffic.
5. What is the purpose of TCP ports 22, 80 and 443 in this exercise?
Port 22 (SSH) is used for secure remote command-line administration of the VM. Port 80 (HTTP) is used by Apache to serve the webpage to browsers. Port 443 (HTTPS) is reserved for encrypted web traffic in a later exercise; its rule was created but not tested.
6. Why should SSH access on port 22 be restricted to trusted IP addresses where possible?
SSH ports open to the whole internet are constantly scanned and attacked with automated brute-force and password-guessing attempts. Restricting the source to trusted IP addresses greatly reduces the attack surface so that only known machines can attempt to log in, which is especially important when password authentication is used.
7. What is Apache HTTP Server, and what is the purpose of the httpd service?
Apache HTTP Server is a free, open-source web server that accepts HTTP requests from clients and returns web content. On AlmaLinux and other Red Hat-based systems it runs as the httpd (HTTP daemon) service, which runs in the background, listens on port 80 (and 443 when configured) and serves files from /var/www/html.
8. What is the difference between starting a service and enabling it?
Starting a service (systemctl start httpd) runs it immediately, but it will not run again after a reboot. Enabling a service (systemctl enable httpd) configures it to start automatically at every boot but does not start it now. The command systemctl enable --now httpd does both.
9. Why does opening port 443 in an NSG not automatically make a website available over HTTPS?
The NSG rule only allows traffic to reach the VM. For HTTPS to work, the web server must also have a valid SSL/TLS certificate (for example from Let's Encrypt), the SSL module (mod_ssl) must be installed and configured, and Apache must be listening on port 443. Without these, nothing on the VM can answer an HTTPS request.
10. What is the difference between HTTP and HTTPS?
HTTP transfers data in plain text, usually on port 80, so it can be read or modified by anyone on the network path. HTTPS is HTTP over TLS, usually on port 443; it encrypts the traffic, verifies the server's identity with a certificate and protects data integrity.
11. What is the difference between accessing the website using a public IP address and using an Azure DNS name?
A public IP address (e.g. 102.37.17.124) is a numeric address that is hard to remember and may change if it is dynamic and the VM is deallocated. An Azure DNS name label gives a human-readable fully qualified domain name (e.g. name.southafricanorth.cloudapp.azure.com) that resolves to the IP through DNS, making it easier to remember and share and stable even if the underlying IP changes. In this task the DNS label was not configured, so the public IP was used.
