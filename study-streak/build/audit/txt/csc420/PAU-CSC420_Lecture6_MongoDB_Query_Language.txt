Recap: Lecture 5
A MongoDB database holds collections of BSON 
documents; every document has a unique _id.
Create: insertOne, insertMany. Read: find and 
findOne, with a filter and a projection.
Update: updateOne with $set and $push. Delete: 
deleteOne.
Dot notation reaches inside embedded documents, 
and matching an array field matches any element.
Today: richer updates, query conditions, and working 
inside arrays and nested documents.

Update Operators
An update names what to change with an 
operator, so the rest of the document is kept:
▪ $set sets a field and $unset removes one;
▪ $inc adds to a number and creates the field if it is 
missing;
▪ $push, $addToSet and $pull change arrays (later 
today).
updateOne changes the first match; updateMany 
changes every match. deleteOne and deleteMany 
work the same way.

$inc and $unset
Adaeze earns 150 loyalty points. She has no 
loyalty_points field yet, so $inc creates it: the schema is 
flexible.
Halima has no mobile numbers, so $unset removes her

  { $inc: { loyalty_points: 150 } })
db.users.updateOne({ _id: 3 },
  { $unset: { mobiles: "" } })

Query Conditionals
A condition goes inside the field's value: 
{field: {$operator: value}}.
Comparison: $gt (>), $gte (≥), $lt (<), $lte (≤), 
$ne (≠).
Lists: $in matches any value in a list, like SQL's IN; 
$nin matches none of them.
Several conditions in one filter must all be true, 
like AND in SQL.
Dr. Stephen A. Adubi

Practical 4 
—
 
Ranges
Two conditions on one field give a range, like BETWEEN: 
find the orders between ₦20,000 and ₦50,000.
Dates compare the same way: find the orders since 1 
August 2026.
db.orders.find(
  { total_amount: { $gte: 20000, $lte: 50000 } },
  { total_amount: 1 })
db.orders.find(
  { order_date: { $gte: ISODate("2026-08-01") } })

Practical 6

$in with distinct
Orders store only user_id, so the orders of users in 
Abeokuta or Lagos take two reads, as in Lecture 5: their 
_ids first, then their orders.
distinct returns a field's values as a plain array, [1, 7, 
10], which $in takes as it is. find returns a cursor instead, 
so some_users._id would be undefined and match 
nothing.
const some_users = db.users.distinct("_id",
  { "address.city": { $in: ["Abeokuta", "Lagos"] } })
db.orders.find({ user_id: { $in: some_users } },
               { user_id: 1, total_amount: 1 })

OR Queries
$or takes an array of filters and matches 
documents that satisfy at least one: Binatone 
products (manufacturer 9) or bestsellers.
For alternatives on the same field, use $in 
instead, as in Practical 5.
db.products.find({ $or: [ { manufacturer_id: 9 },
           { tags: "bestseller" } ] }, { name: 1 })

Practical 8 
—
 
$not vs $lte
Only Adaeze has loyalty points, and she has more 
than 100. So why do these counts differ?
$not also matches documents without the field: the 
nine other users. $lte matches only documents that 
have it.
db.users.countDocuments(
  { loyalty_points: { $not: { $gt: 100 } } })   // 9
db.users.countDocuments(
  { loyalty_points: { $lte: 100 } })            // 0

Working Inside Documents
Nested documents: reach a field with dot notation, 
e.g., "address.city".
Arrays of values: match one element, all listed 
elements ($all), or an exact length ($size).
Arrays of documents: apply several conditions to one
element with $elemMatch.
Projection: return part of an array with $slice or the 
positional $.
Updates: $addToSet, $pull and the positional $ 
change arrays in place.
Dr. Stephen A. Adubi

Nested Documents
Matching a whole embedded document needs an 
exact match: every field, in the same order. Both 
Lagos users have more fields in their address, so the 
first query finds none.
Dot notation matches just the field: two users.
db.users.countDocuments(
  { address: { city: "Lagos" } })     // 0
db.users.countDocuments(
  { "address.city": "Lagos" })       // 2

Practical 10

$all and $size
$all: the array must contain every listed value, in 
any order: the Baygon aerosol.
$size: the array has exactly that many elements; the 
kettle has no tags. $size does not accept ranges such 
as $gt.
db.products.find(
  { tags: { $all: ["bestseller", "insecticide"] } },
  { name: 1 })
db.products.find({ tags: { $size: 0 } }, { name: 1 })

Mixing Elements
Intended Goal: a variation that is both cheap (under 
₦5,000) and low in stock (under 100).
With dot notation, each condition may be met by a
different variation. Milo matches: one variation is 
under ₦5,000, but a different one is low in stock.
db.products.find(
  { "variations.price": { $lt: 5000 },
"variations.qty_on_hand": { $lt: 100 } },
  { name: 1 })   // Baygon aerosol, Milo, Indomie

$elemMatch
$elemMatch requires one element to meet every 
condition.
Only the Baygon aerosol has a single variation 
that is both: ₦3,500 with 85 in stock.
db.products.find(
  { variations: { $elemMatch:
      { price: { $lt: 5000 }, qty_on_hand: { $lt: 100 } } } },
  { name: 1 })   // Baygon Multi-Insect Killer Aerosol

Practical 13

$slice and $
$slice: 1 returns the first variation only; -1 would 
return the last.
"variations.$" returns the first element that
matched the filter: the Samsung variation that is out 
of stock.
db.products.findOne({ _id: 8 },
  { name: 1, variations: { $slice: 1 } })
db.products.find({ "variations.qty_on_hand": 0 },
  { name: 1, "variations.$": 1 })

Practical 14

Updating Arrays
$addToSet adds a value only if it is not already
there: run it twice, and the second time 
modifiedCount is 0.
$pull removes every matching element: the Camon 
30 is no longer a new arrival.
db.users.updateOne({ _id: 9 },
  { $addToSet: { favourite_tags: "bestseller" } })
db.products.updateOne({ _id: 8 },
  { $pull: { tags: "new arrival" } })

Wrap
-
Up: Key Takeaways
Updates name what to change: $set, $unset and $inc; 
updateMany and deleteMany act on every match; 
upsert: true inserts when nothing matches.
Conditions sit inside a field: $gt, $gte, $lt, $lte, $ne, 
$in and $nin. Fields in one filter are ANDed; $or offers 
alternatives; $not reverses a condition and also 
matches missing fields.
Arrays and nested documents: dot notation, $all, 
$size, $elemMatch for one element, $slice and $ to 
return part of an array, and $addToSet, $pull and $ to 
update it.
